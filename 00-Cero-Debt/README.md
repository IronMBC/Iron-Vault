CERO-DEBT CONTRACT

A DEBT = a specific capability I cannot reliably demonstrate.

A debt is NOT:
- something merely interesting
- something I have never encountered
- something I deliberately chose to learn later

A debt IS:
- something I thought I knew but discovered I don't
- something I repeatedly forget
- something blocking practical work
- something I can recognize but cannot explain/use independently

STATES:
    DEBT       → identified gap
    ACTIVE     → currently attacking it
    PROVING    → understanding acquired; testing independence
    CLOSED     → demonstrated without assistance/notes

PRIORITY:
    P0 → blocking current progress
    P1 → core foundation
    P2 → useful
    P3 → deliberately deferred

CLOSURE:
    Understand → reconstruct → apply → recognize independently

RULE:
    "I understand it" is not proof.
    Demonstration is proof.
